## 💾 ARCHIVOS POR CARPETA (Después de migración)

### `frontend/src/` (React mejorado)
```
├── api/services/        ← NUEVO: Servicios centralizados
├── hooks/              ← NUEVO: Custom hooks reutilizables
├── context/            ← NUEVO: State global
├── components/         ← Reorganizado: shared, layout, features, dialogs
├── pages/              ← Reorganizado: dashboard, management, config, reports
├── utils/              ← Limpiado: Solo funciones puras
├── config/             ← NUEVO: Configuración centralizada
└── types/              ← Renombrado de entities/
```

### `backend/` (Django)
```
├── config/             ← Django settings
├── apps/              ← Django apps por entidad
│   ├── usuarios/      ← Auth (NUEVO)
│   ├── clientes/      ← Clientes (NUEVO)
│   ├── ventas/        ← Ventas (NUEVO)
│   ├── alertas/       ← Alertas (NUEVO)
│   └── webhooks/      ← Functions → Django handlers (NUEVO)
├── utils/             ← Utilidades backend
└── scripts/           ← Management scripts
```

### `landing/` (Marketing)
```
├── src/components/    ← Hero, Features, Pricing, etc.
├── src/pages/         ← Home, About, Contact, etc.
└── src/styles/        ← Estilos CSS/Tailwind
```

### `docs/` (Documentación)
```
├── arquitectura/      ← Documentos técnicos
├── guias/            ← Tutoriales prácticos
├── api/              ← Documentación API
├── negocio/          ← Reglas de negocio
└── deployment/       ← DevOps y deployment
```
