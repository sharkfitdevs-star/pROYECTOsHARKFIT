### Descripción
- **backend/**: Lógica de negocio principal, apps y utilidades Python.
- **backend-data-intake/**: Ingesta de datos y APIs Node.js.
- **users-microservice/**: Microservicio de usuarios.
- **frontend/**: Aplicación React principal.
- **landing/**: Landing page React.
- **docs/**: Documentación técnica y de negocio.
- **scripts/**: Scripts de utilidad generales.
- **Archivos raíz**: Documentos y archivos HTML principales.

> Esta estructura facilita la separación de responsabilidades y el mantenimiento del proyecto.
